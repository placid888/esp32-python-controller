角色控制台：新手操作說明

第一次使用：先不用連 ESP32
1. 在「角色與狀態」選好設定檔、職業與專精。
2. 看「設定進度總覽」及「設定提醒」，確認哪些待設定、待校準、待測試。
3. 沒有學到技能時，技能與資源提示可以先保持停用，不用填猜測的技能花費。
4. 上方切換「進階」模式，再到「進階工具」按「一鍵離線自我檢查」。這不需要開魔獸，只檢查模擬邏輯。

想看怒氣／集中值
1. 確認遊戲版面、資源條位置及解析度沒有變。
2. 主頁按「怒氣唯讀監控」或「集中值唯讀監控」，再按小窗的開始。
3. 點一下魔獸畫面，讓魔獸位於前景；不要讓其他視窗遮住資源條。
4. 看數值是否跟遊戲一致。監控小窗停止後顯示「已停止」是正常，不代表校準失敗。
5. 若顯示無法讀取，先檢查前景視窗、遮擋、1920×1080解析度及對應的Clean版面。

「完成」到底表示什麼？
- 戰士「讀值驗證已完成」：特定 Warrior Clean／1920×1080 歷史截圖通過比對，並非自動確認現在版面或全部專精。
- 獵人「待實機校準」：集中值還需要遊戲內對照，模擬測試不能代替。
- 「已儲存／已啟用」：只是設定存在，不等於校準成功或技能可以施放。
- 「離線檢查通過」：只表示本次版本的模擬案例通過，並不是實機校準完成。
- 「未知」：程式沒有足夠證據；不會把未知當作可以施放。

有技能之後再設定
1. 上方切換「進階」模式，再到「技能與採色」設定格子與採色，固定優先順序為1→2→3→4→5→6→7→8→9→0。
2. 進階模式→「技能與採色」→「技能名稱與資源條件」，按「怒氣／集中值條件設定」填入技能名稱及資源區間，依真正技能說明填寫，不要猜。
3. 採色開關與資源提示開關是兩套設定，主頁會分開顯示。
4. 資源數值在區間內只表示資源條件符合，不代表冷卻、距離及技能可用性也符合。
5. 冷卻／距離／技能可用性目前尚未整合，資源功能只監控與提示，不自動按鍵。

測試及備份
- 一鍵離線自我檢查：不操作遊戲、不連硬體、不擷取畫面；可在未開魔獸時執行。
- 整合判斷模擬：全部是手動輸入的假資料，不會儲存，也不會施放技能。
- 修改前可先切進階模式，再到「進階工具」備份已儲存設定；尚未儲存的編輯內容不在備份內。
- 還原前須停止監控、UDP、採色與校準，並關閉其他小窗；還原會先備份目前設定。
- 備份只含控制台設定，不含魔獸插件、程式碼或ESP32韌體。不要公開分享含內網資訊的備份。

安全提醒
資源功能不會自動按鍵，但控制台其他UDP測試功能仍可能操作硬體；不需要時維持Dry Run，不要初始化UDP。
若不確定目前狀態，先按主頁「停止監控與UDP」。這不保證裝置本身已解除所有按鍵。
移動資源條或改解析度後，需要重新核對讀值；不要沿用舊驗證就當作準確。

技能分類與流程預覽
- 技能概覽可看到分類：產怒／消怒（或產生／消耗集中值）、防禦、位移、中斷，以及不分類。
- 分類只是標記；不會因為標成防禦就自動保命，也不會因標成中斷就判斷敵人施法。
- 上方切進階模式→「進階工具」→「技能分析工具」→「技能流程預覽」，可讀取已儲存條件，配合手動假狀態看每一格的中文原因。
- 不需要已有技能：按「載入假資料示範」，會使用五格假技能與全部符合的假狀態。20與80可示範產／消資源分流。
- 示範的0–39、40–100只是假區間，不是真實技能花費。示範不會存入設定、不控制按鍵、不校準畫面。
- 選取一格可改採色／冷卻／距離／可用性的假狀態；未知會阻擋，順位在後的技能會標示「符合但順位較後」。
- 修改模擬數值後，按「更新預覽」。更換設定檔或職業／專精後，請關閉並重新開啟預覽。

技能設定精靈與一鍵情境
- 「角色與狀態」頁按「技能設定精靈」，依序填：技能格與名稱→分類→資源區間→採色座標→檢查儲存。
- 不知道花費可先保留0–100，但務必稍後依真正技能確認；分類不會自動推測資源或施放時機。
- 採色可暫時保留原設定，日後回「技能與採色」用F8或校準工具；精靈不採集畫面，也不驗證座標。
- 儲存前會備份，且只更新目前專精的一格。這一格的採色與資源提示都會停用，即使原本已啟用；最後會再次詢問。
- 監控、UDP、採色、校準或其他編輯小窗未關閉時，不允許使用精靈儲存。資料變更時會拒絕覆寫，請重開精靈。
- 流程預覽新增低資源20、滿資源100、選取格冷卻中、選取格距離不足、全部條件未知。
- 一鍵情境會重設所有假證據：除指定阻擋外其餘假證據設為符合；全部未知則全部設未知。不是目前遊戲狀態。
- 情境不會啟用停用中的規則，也不會儲存。沒有技能時可先載入假資料示範。

專精比較與編輯／測試狀態
- 上方切進階模式→「進階工具」→「技能分析工具」→「專精差異比較」，可選同一設定檔的任意兩個職業／專精，只看已儲存的差異，不切換、不複製、不覆蓋。
- 比較包含技能名稱／分類／資源提示條件、採色欄位與相關專精條件；不是傷害或實際打法比較。
- 主頁「編輯與測試狀態」會區分未儲存修改、已與磁碟一致、手動模擬結果與完整實機技能測試待測。
- 示範假資料不算已儲存技能條件通過；手動模擬有候選，也只表示當時手動輸入符合，不代表遊戲可施放。
- 資源條件變更後，舊手動模擬不適用，必須重測。結果只在本次控制台工作階段記憶，重開後不冒稱測試完成。
- 完整實機技能測試與資源讀值驗證分開顯示，不能把戰士怒氣截圖通過當作全部技能完成。

簡易／進階模式與待實測清單
- 控制台預設簡易模式（每次開啟重設，不改config），保留選角色、唯讀監控、技能精靈、狀態與待實測清單。
- 上方切到進階模式才顯示「技能與採色」「進階工具」頁及完整技能概覽；流程預覽與專精比較在進階工具的技能分析區。
- 切換只改顯示，不會停止正在執行的監控、不會改Dry Run／UDP輸出模式，也不會關閉已開啟的小窗。停止按鈕與輸出狀態仍保留。
- 待實測清單預設全部待測，按Profile／職業／專精分開保存手動狀態、備註與時間。手動回報通過不等於程式驗證。
- 設定變更後舊回報會標示需重測；不會自動把戰士讀值舊驗證套用到其他專精，也不會解除集中值校準限制。
- 手動清單在config旁的manual_test_checklist.json，與config分開。既有「設定備份」只備份config，不包含清單；可另存清單檔或匯出已儲存清單。
- 清單只是安排下次測試，現在不用開魔獸或連ESP32；不會自動執行任何測試、採色或按鍵。

功能入口整理（目前版本）
- 日常入口只有「角色與狀態」的唯讀監控、技能設定精靈與待實測清單。
- 技能名稱／分類／資源區間：進階模式→技能與採色→技能名稱與資源條件。採色與原有F8工具仍在同頁下方。
- 流程預覽／專精比較／進階逐格訊號模擬：進階工具→技能分析工具。舊逐格模擬保留，不刪功能。
- 一鍵離線自檢與本次報告：進階工具→離線自我檢查。新手說明統一使用上方「新手說明」。
- 重複的精靈、資源條件及跨頁按鈕已合併；各區停止按鈕屬安全控制，刻意保留。
- 這只是入口整理，不會改設定、開關、技能優先順序或輸出模式。
